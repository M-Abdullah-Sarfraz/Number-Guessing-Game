**Number Guessing Game 🎲**
A simple Python-based Number Guessing Game where the user tries to guess a randomly generated number between 0 and 100. The player has a limited number of chances to guess the correct number.

**Features**
Random Number Generation: The program generates a random number between 0 and 100.
Limited Attempts: The player gets 3 attempts to guess the number.
Guided Feedback: After each guess, the program provides hints indicating whether the guess was too high or too low.
Winning Condition: The game ends if the player guesses the correct number within the allowed attempts.
Losing Condition: If the player fails to guess the number within 3 attempts, they lose the game.
**Instructions to Play**
Run the Python script.
The program will display a welcome message and game instructions.
Enter your guesses when prompted.
Use the feedback after each guess to guide your next attempt.
The game ends when:
You guess the correct number, or
You exhaust all 3 attempts.
